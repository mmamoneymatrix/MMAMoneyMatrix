5.2 Components (Advanced Breakdown)
The Matchup Logic Engine evaluates six major component groups.
Each group contributes numeric modifiers that shape the fightGeometry object.

1. Style vs Style Interaction
This is the behavioral core of the engine.
Each fighter’s style tags generate vectors that interact with the opponent’s vectors.

Examples of interactions
Pressure vs Counter  
Pressure increases tempo; counter increases precision → countering advantage.

Wrestler vs Striker  
Wrestler increases takedown probability; striker increases range control → grappling advantage.

Kick-heavy vs Grappler  
Kick-heavy increases distance control; grappler increases takedown entries → takedown vulnerability.

Cardio Monster vs Slow Starter  
Cardio monster gains late-round advantage; slow starter gains early-round advantage.

What this produces
Range modifiers

Pace modifiers

Grappling modifiers

Chaos modifiers

Early/late round modifiers

🧩 5.3 Output — fightGeometry Object (Advanced Breakdown)
After processing all components, the engine produces a fightGeometry object.

This object is the blueprint for the Monte Carlo Simulation Engine.

Here is the full structure:

Code
fightGeometry = {
  rangeControl: number,
  paceControl: number,
  grapplingAdvantage: number,
  strikingAdvantage: number,
  chaosFactor: number,
  cardioAdvantage: number,
  earlyRoundAdvantage: number,
  lateRoundAdvantage: number,
  finishThreat: number,
  vulnerability: number,
  gymTierModifier: number,
  contextModifier: number
}
Below is what each field represents.

rangeControl
How well a fighter controls distance:

reach

height

stance

kick-heavy vs boxer

wrestler entries vs striker range

Positive = Fighter A controls range
Negative = Fighter B controls range

pressure

volume

cardio

slow/fast starter

scramble success

accuracy
