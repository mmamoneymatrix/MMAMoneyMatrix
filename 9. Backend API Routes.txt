🧩 Component Map (Expert Mode)
This is the full UI component architecture, showing how everything connects.

1. <FighterImport />
Purpose: Import fighters into the system.

Used in:  
app/page.tsx

Responsibilities:

Search fighter by name

Import fighter by UFC URL

Display import success

Set fighterA or fighterB in parent state

2. <FighterCard />
Purpose: Display fighter summary.

Used in:  
/fighters, /fighters/[id], matchup pages

Responsibilities:

Show name, record, gym, styles

Click → navigate to fighter profile

3. <FighterProfile />
Purpose: Full fighter breakdown.

Used in:  
/fighters/[id]

Responsibilities:

Bio

Career stats

Striking metrics

Grappling metrics

Style tags

Derived metrics

4. <MatchupRunner />
Purpose: Select Fighter A + Fighter B → run simulation.

Used in:  
app/page.tsx

Responsibilities:

Choose fighters

Call /api/matchup/run

Show <LoadingSimulation />

Pass results to <MatchupResult />

5. <MatchupResult />
Purpose: Display the full simulation output.

Used in:  
/matchup/page.tsx

Responsibilities:

Win probability

Method breakdown

Round breakdown

Confidence ranges

AI explanation

Scenario toggles

6. <MethodBreakdown />
Purpose: KO/TKO, SUB, DEC probabilities.

Used in:  
<MatchupResult />

Responsibilities:

Show method percentages

Show method-by-round charts

Color-coded bars

7. <ConfidenceRanges />
Purpose: Show confidence intervals.

Used in:  
<MatchupResult />

Responsibilities:

95% CI

High/Medium/Low confidence labels

Error bars

8. <ScenarioPanel />
Purpose: Scenario analysis.

Used in:  
<MatchupResult />

Responsibilities:

Toggles:

Short notice

Altitude

5-round fight

Remove gym bonus

Calls /api/matchup/scenario

Shows probability shifts

9. <ProbabilityChart />
Purpose: Visual probability display.

Used in:  
<MatchupResult />, <MethodBreakdown />

Responsibilities:

Donut charts

Bar charts

Stacked charts

10. <LoadingSimulation />
Purpose: Simulation progress indicator.

Used in:  
<MatchupRunner />

Responsibilities:

“Simulating 10,000 fights…”

Animated progress bar
