MMAMoneyMatrix — Developer Documentation
1. Overview
MMAMoneyMatrix is a modular MMA fight simulation engine built on:

Structured fighter ingestion

Style-based matchup logic

Monte Carlo simulation

Realistic scoring and judging

Finish probability modeling

Bonus layers (Gym Tier + Underdog)

AI explanation output

The system is designed for real-world prediction, not just entertainment.

2. Architecture
Core subsystems:

Fighter Data Ingestion System

Monte Carlo Simulation Engine

Finish Probability Engine

Scoring & Judging Model

Raw Probability Output

Bonus Layer

Normalization Layer

Final Output + AI Explanation

3. Fighter Data Ingestion System
3.1 Data Sources
UFC stats (striking, grappling, fight history)

UFC fighter profiles (bio, stance, gym, reach, height)

Record book (leaders, streaks, bonuses)

AI extraction for unstructured pages

Manual overrides for edge cases

3.2 Fighter Object Structure
Each fighter is stored as:

Bio: name, age, height, reach, stance, weight class, country, gym

Career: wins, losses, draws, KO/Sub/Dec splits, total fights, streaks, layoff, years active

Striking: sig strikes per minute, absorbed per minute, accuracy, defense, knockdown rate, tempo, power index, strike differential

Grappling: takedown accuracy/defense, control time, submissions, scrambles, ground-and-pound rate

History: list of fights with opponent, result, method, round/time, event, notes

Styles: array of tags (pressure_striker, counter_striker, wrestler, grappler, brawler, cardio_monster, etc.)

Gym Tier: S/A/B + numeric bonus

Underdog Level: mild/medium/strong/heavy + numeric bonus

Derived Metrics: cardio index, momentum index, damage tolerance, striking/grappling differential

5. Matchup Logic Engine
5.1 Inputs
fighterA and fighterB objects

All stats, styles, derived metrics

Context (short notice, altitude, weight class changes)

5.2 Components
Style vs Style Interaction: pressure vs counter, wrestler vs striker, kick-heavy vs grappler, cardio monster vs slow starter, etc.

Stat Differentials: striking, grappling, cardio, derived metrics.

Physical Attributes: height, reach, age, stance.

Historical Patterns: common opponents, improvement/decline curves, activity level, damage accumulation.

Context Factors: short notice, altitude, travel, injuries.

Gym Tier Modifier: elite vs small gym advantage.

6. Monte Carlo Simulation Engine
6.1 Structure
Simulates N fights (e.g. 5,000–50,000).

Each simulation runs 3 or 5 rounds.

6.2 Round Engine
Per round:

Set pace using paceControl, cardioAdvantage, styles.

Generate striking exchanges (accuracy, defense, power, rangeControl).

Generate grappling exchanges (takedowns, control, submissions).

Apply chaosFactor for wild events.

Track damage and fatigue, updating fighter state.

6.3 Outcomes
If finish triggers → KO/TKO/SUB result.

If no finish → pass to scoring & judging model.

6.4 Aggregation
After all simulations:

Win counts per fighter.

Method counts (KO/SUB/DEC).

Round-of-finish counts.

Convert to probabilities + confidence intervals.

7. Finish Probability Engine
7.1 Inputs
Power index, knockdown rate, strike differential, damage tolerance.

Grappling threat, control time, submission attempts.

chaosFactor, finishThreat, vulnerability, fatigue.

7.2 KO/TKO Logic
Base KO chance from power, knockdowns, strike differential, accumulated damage.

Modifiers from chaosFactor, cardio drop, styles (brawler, KO artist, pressure striker).

7.3 Submission Logic
Base SUB chance from submissions, grapplingAdvantage, control time, scrambles.

Modifiers from fatigue, damage, styles (grappler, submission hunter).

7.4 Round Distribution
Tracks when finishes occur (R1–R5) for method-by-round probabilities.

8. Scoring & Judging Model
8.1 Inputs
Per round:

Strikes landed/absorbed, knockdowns.

Control time, takedowns, submissions.

Pace, pressure, damage indices.

8.2 Criteria
Effective striking.

Effective grappling.

Aggression & octagon control.

8.3 Scoring
10–9: clear winner.

10–8: dominant round.

10–7: extreme domination.

Simulates multiple judges with bias profiles.

8.4 Decisions
Unanimous, split, majority, draw.

Produces decision outcome probabilities.

Underdog Bonus (mild/medium/strong/heavy).

Applied to raw probabilities.

9.2 Normalization
Ensures total probability = 100%.
